STOMMS API Documentation
========================

This section provides a set of API's for the users to read mesh information from the adios2 mesh files.
Developers should consult the `STOMMS Native Doxygen Doc <../../doxygen_html/index.html>`_ for complete details of the STOMMS data types and API's.
The doxygen document contains the details of both ``stomms_meshgen`` and ``stomms_reader`` code.
